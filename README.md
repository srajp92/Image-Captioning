# Image Captioning with CLIP and GPT-2 (IE 7615 Generative Project)
Milestone 1: baseline pipeline for COCO Captions (1,000 images, ~5k pairs)

## Files
- `Milestone1_Image_Captioning.ipynb`: data cleaning, CLIP image embeddings,
  GPT-2 tokenization, 5 baseline image→caption test runs
- `IE 7615 Generative Project Proposal.pdf`: initial project proposal
- `data`: cleaned captions and sample test-run outputs

## How to run
1. Open the notebook in Google Colab (GPU runtime: T4)
2. Run all cells top to bottom. All required packages are installed in the first cell
   (Or `pip install -r requirements.txt` locally)
